# Martonology — Budapest demo

Statikus, reszponzív SCH Agency outreach-weboldal demo.

- Helyszín: Budapest VII., Király u. 83.
- Elsődleges CTA: Facebook üzenetes időpontkérés
- Nincs háttér-automatizáció vagy szerveroldali foglalás
- Van reszponzív navigáció, animáció, reduced-motion támogatás, Google Maps CTA és kliensoldali üzenet-összeállító

A bemutató kizárólag igazolt, nyilvános lead-információkra épül; nincs kitalált ár, értékelés vagy nyitvatartás.
